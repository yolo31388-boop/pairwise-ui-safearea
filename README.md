# pairwise-ui-safearea

游戏 UI 一上异形屏就错位：安全区只读了一次，折叠屏展开后没有重新布局；anchor 用屏幕百分比，刘海屏把血条顶到挖孔下面；不同 DPI 下字号按 px 写死，平板上的按钮小到点不到；横竖屏切换时缓存了旧分辨率，布局整体偏移；多语言文本变长后按钮溢出，没有做省略和换行；安全区和键盘弹起区域重叠，输入框被遮住。ui/layout.py 是核心，tests/test_layout.py 15个红。要修的是：监听安全区变化；anchor 相对安全区；字号按 DPI 和可读性缩放；旋转时重算布局；文本溢出省略/换行；键盘区域参与避让。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
